# Pixel-art Eastern Kingdoms: three methods

Experiment, **not wired into the addon**. Three ways to make a high-definition pixel-art Eastern Kingdoms
(uiMapID 1415, Forever build 1.60.1.70862) that lines up with Meridian's stitched continent. Pick one before any
addon work.

| | Method | Folder | In git |
|---|---|---|---|
| A | Stylize Blizzard's zone map art | `a-stylize/` | README only (derived from Blizzard art) |
| B | Procedural from game data, no Blizzard art | `b-scratch/` | yes |
| C | B + hand-drawn landmarks | `c-hybrid/` | yes |

`compare.png` (git-ignored: it contains Method A pixels) puts the three side by side: the continent (every 4th pixel) and the three preview crops at 2x.
Each folder has `full.png` (whole continent, 1 px = 1 art pixel), `<name>.aseprite`, `tiles/` and three crops,
each at 1x and 4x nearest-neighbour: `stormwind-elwynn`, `ironforge-dunmorogh`, `steppes-gorge`.

Rebuild everything: `tools/pixelmap/build_all.sh <work dir>` from the repo root (about 2.5 min once the inputs are
cached; first run also fetches CascLib, DB2 CSVs and the listfile). Work dir must be outside git.

## Grid and alignment (how pins will line up)

All numbers are in `layout.json`, generated by `tools/pixelmap/layout.py` from the build's DB2 tables.

- **Canvas** = Meridian's continent canvas from `Canvas:BuildContinent`: `YARDS_TO_PX = 0.35`, map x follows
  **-worldY**, map y follows **-worldX**, origin at the min corner over every zone child of 1415 (26 zones incl. the
  three cities and Forever's Riverglades): `minx = -3450.0`, `miny = -3837.5` yards, so
  `canvas = ((-worldY) - minx, (-worldX) - miny) * 0.35`. Canvas size 3567.1 x 6741.1.
  Zone rects (`zones[].rect`) are computed exactly as Meridian does (UiMapAssignment region = what
  `C_Map.GetWorldPosFromMapPos` returns for the 0..1 corners).
- **Art grid**: 1 art pixel = `artScale` = **2 canvas units** (0.175 px/yard, about 5.7 yards per pixel).
  Art size 1784 x 3371. Art pixel (ax, ay) covers canvas [2ax, 2ax+2) x [2ay, 2ay+2).
- **Tiles**: 256 x 256 indexed PNGs, `tiles/rRR_cCC.png`, row-major from the top-left; 7 x 14 tiles (padded to
  1792 x 3584 art px with deep ocean). Tile (r, c) covers canvas x in [512c, 512c+512), y in [512r, 512r+512).
  In the addon each tile would be one texture of size 512 x 512 canvas units at `TOPLEFT (512c, -512r)` with
  nearest filtering; integer zoom levels keep the pixel grid crisp.
- **If the client's zone set differs** (e.g. a zone hidden or added), Meridian's own `stitch.minx/miny` will differ
  from `layout.json`: shift the tile grid by `(layout.minx - stitch.minx) * 0.35` and the same for y, or rebuild.
  The rects were checked against the DB2 data only, not against a live client.

## Sources and provenance

- **Local client** (`World of Warcraft/Data`, product `wowf`), read-only through **CascLib**
  (github.com/ladislav-zezula/CascLib, MIT, built in the work dir; `casc_extract.py` is a ctypes wrapper): the
  Azeroth WDT (775971), 736 root/obj0/tex0 ADT triples (all local) and 371 of the 880 map tiles Method A needs.
- **wago.tools** (https://wago.tools): DB2 tables as CSV for build 1.60.1.70862 (UiMap, UiMapAssignment, UiMapArt*,
  WorldMapOverlay*, AreaTable, LiquidType, ...), and the **509 map tiles the local storage does not hold** (the
  launcher streams them on demand): `https://wago.tools/api/casc/<fileDataID>?download&version=1.60.1.70862`.
  wago mirrors Blizzard's CDN; one locally extracted tile was compared byte-for-byte and matched. No licence is
  granted: the files are Blizzard's copyright, fetched for a local, private preview only, kept in the work dir.
- **wowdev community listfile** (github.com/wowdev/wow-listfile, release `community-listfile.csv`): file *names*
  for texture and model IDs, used by Method B to classify ground textures and doodads. Not redistributed.
- **ForeverDungeonJournal** (installed addon, `Data/DungeonEntrances.lua`): dungeon entrance positions.

## Methods in short

- **A** (`a_source.py`, `a_stylize.py`, `a_finish.lua`): zone art = base tiles + every exploration overlay
  ("fully revealed"). Each pixel takes the art of the zone that owns that ground (terrain area IDs, borders
  jittered), so other maps' parchment frames and neighbour previews drop out; frames at rect edges are replaced by
  mirrored interior art. Then median 3, box downscale, Bayer 4x4 ordered dither into a 44-colour palette (k-means
  seed, hand-tuned), terrain-data water bands, 1 px coast outline, data roads, Aseprite despeckle + export.
- **B** (`terrain.py`, `features.py`, `prep_b.py`, `b_render.lua`): heights (MCVT), liquids (MH2O), area IDs, ground
  material from texture-name keywords x alpha weights (tex0), tree and WMO placements (obj0). Aseprite composes:
  48-colour palette, 3-shade ramps per biome x NW hillshade with ordered dither, distance-banded sea, coast outline,
  roads, roofs, 78k tree sprites, gate markers.
- **C** (`c_landmarks.lua`): B plus sprites at real WMO/entrance positions and procedural Stormwind/Blackrock.

Palettes: `tools/pixelmap/palettes/*.gpl` (load in Aseprite with Palette > Load).
