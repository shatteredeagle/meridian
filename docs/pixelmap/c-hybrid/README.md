# Method C: B + hand-drawn landmarks

Made by `tools/pixelmap/build_b.sh <work dir> c`: Method B's terrain plus `tools/pixelmap/c_landmarks.lua`, which
places hand-drawn sprites (Ironforge gate, Lordaeron, Karazhan, Scarlet Monastery, Zul'Gurub, Stromgarde,
Shadowfang, Stratholme, Uldaman, Gnomeregan, Deadmines, Sunken Temple, Dalaran, Gilneas) at their WMO or entrance
positions, a procedural walled Stormwind (districts, canals, cathedral, keep) and a shaded Blackrock Mountain cone.
No Blizzard pixels.
