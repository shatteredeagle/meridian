# Changelog

Unreleased (after 0.1.2-alpha):

- Continent view: each zone's explored/revealed overlay detail is drawn in a layer above every zone's base art. A neighbouring zone's base (which paints other zones as blank parchment) used to cover it at the seams, which looked like hidden terrain with Reveal map on (Westfall/Elwynn, Darkshore, Ashenvale edges). Added `/mm overlays` coverage diagnostic.

- Ground that no zone map covers (open sea off the coast, gaps between zones on the continent view) is drawn in a sea colour instead of black, on the main map and the minimap.

- Minimap resizes to any shape: the bottom-right grip sets width and height independently (100 to 800 px each, saved). The options "Minimap size" slider resets it to a square. A round minimap becomes an ellipse.

- Minimap sits on the LOW frame strata, so bags, panels and dialogs draw over it instead of the other way round.

- Minimap: resizing keeps your zoom (mouse-wheel zoom is now saved as the minimap zoom) and never drops follow-me; if you had panned away, the same spot stays centred.

- Minimap: right-click opens a menu (zoom, follow me, quest areas / givers / arrow / coordinates / lock toggles, open map, options, hide).

- Minimap is always fully revealed (no dimmed "unexplored" patches, whatever the main map's art setting), and its move strip is only drawn while the mouse is over it.

- Minimap: move strip, resize grip and follow button now sit above the canvas (they were covered and never got the mouse); new installs default to the square minimap (existing saves keep their setting: uncheck "Round minimap" and /reload).

- Minimap: bottom-right grip resizes the square (120 to 600 px, saved; the options slider follows), and the top move strip is taller (14 px). Locked windows can't be moved or resized.

- Option "Open Meridian with the world map key (M)" (off by default): overrides whatever key is bound to Blizzard's world map (M unless you rebound it) so it toggles Meridian. Turning it off restores the stock binding. Changes made in combat apply when combat ends.

- Options page: content now scrolls and long checkbox labels wrap, so nothing runs off the bottom of the window.

0.1.2-alpha (all items untested in-client unless noted; see docs/test-checklist.md).

- Localization: machine-translated, unreviewed UI text for deDE (now complete), frFR, esES, esMX, itIT, ptBR, ruRU, koKR, zhCN and zhTW (Locales/<locale>.lua). Text uses the client's own fonts, so CJK and Cyrillic render. The locale test checks every key and its format specifiers.

- Quest-giver "!" markers now check profession skill and reputation requirements (QuestieDB requiredSkill / requiredMinRep / requiredMaxRep). If the client can't report skill ids or a faction, the quest stays listed.

- Controller mode: a crosshair marks the map centre; A drops a waypoint there and turns the arrow on, X centres on you, B closes, Y toggles the list, Back toggles pin, D-pad up/down and shoulders cycle quests. Still untested with a real pad.

- Quest objectives that are lootable/interactable objects, or NPCs with 3 or fewer spawns, now draw one small circle per spawn (min 9 px on screen) instead of one big area. Mob camps (4+ spawns close together) and lists over 40 objects still collapse into areas.

- Approved on CurseForge: https://www.curseforge.com/wow/addons/meridian (README links it).

- Map art styles (ArtStyles.lua, experimental): toolbar icon or `/mm art [blizzard|a|b|c]` cycles Blizzard's art and three pixel-art Eastern Kingdoms maps. Tiles live in a local-only addon folder MeridianPixelMaps installed separately (not distributed); without it the pixel styles are unavailable and releases are unaffected. `/mm art shift dx dy` nudges alignment. Needs a full client restart after installing.

- Default view on open (`/mm`): the stitched continent zoomed to about one zone, centred on you and pinned to you. Option "Open zoomed in on me and pinned" (default on; off keeps the last view). Player position now resolves from cities and sub-zones on the stitched continent too (Stormwind etc.), so Find me, the marker and pinning work there.

- Right-click the map to drop a waypoint pin; the direction arrow is switched on and points to it (Ctrl-click still works). Right-clicking an existing pin removes it.

- Pin the map to your character: toolbar pin toggle, `/mm pin`, options checkbox and a key binding. While on, the main map stays centred on you every 0.1 s and follows you into other zones (continent view stays continent, zone view follows the zone). Dragging the map unpins it. New icon `pin.tga` needs a full client restart.

- Explored-only mode no longer dims maps that have no overlay data at all (Stormwind and other cities looked permanently foggy).

- Seamless continent map: every stitched zone gets a feathered alpha mask (Media/feather.tga, generated by tools/gen_feather.py) so overlapping zone art fades into its neighbours instead of showing hard rectangles. Options checkbox and `/mm blend` (default on); zone and dungeon views are unmasked. New texture file: needs a full client restart, not just /reload.

- Dungeon / instance maps (Dungeons.lua). Castle-gate pins mark dungeon entrances on zone and continent maps (own silhouette, not colour alone); click opens the dungeon in the same canvas, multi-floor dungeons get a floor bar (floor buttons, current one bracketed, Back to the map you came from). Dungeons come from ForeverDungeonJournal when installed (client map IDs, or its own tile/texture art when the client has no map), from every C_Map map of type Dungeon with art (grouped into floors by map group), and entrance positions from the journal data, C_EncounterJournal.GetDungeonEntrancesForMap or the map's rectangle on its parent. Quest areas/givers use the existing providers per floor map; with the journal's data, in-dungeon turn-in NPCs get "?" and available pick-ups "!" markers. Player marker and "Find me" work when the client reports a position for a floor; Find me/Zone view open the instance you are in. Search finds dungeons ([Dungeon]). Toolbar doorway toggle, options checkbox, `/mm dungeons`, default on. Custom floors use negative map keys: waypoints and map-ID-based features skip them. New pure helpers and tests.

- Punchlist 1: Waypoints and /way. Ctrl-click the map to drop one; /way x y [title], /way Zone x y, /way #mapID x y, /way list, /way clear (also /mm way ...). Pins on the map and minimap (right-click removes, left-click points the arrow), arrow auto-targets the newest and clears on arrival, newest is mirrored to Blizzard's user waypoint and super-track. TomTom installed: /way is left to it and waypoints are forwarded to it. New teardrop/!/?/arrowhead/star/diamond pin art (tools/gen_icons.py).

- Punchlist 2: Turn-in markers. Green "?" pin (own silhouette, not just colour) at the finisher NPC/object of every completed log quest, from QuestieDB finishedBy (guarded if the DB lacks it). The arrow now points completed quests at their hand-in. /mm turnins toggles.

- Punchlist 3: Key bindings (Bindings.xml, header Meridian): toggle map, minimap, arrow, quest list, center on player. New UI:CenterOnPlayer shared with the Find me button.

- Punchlist 4: Options page (Options.lua): opacity, marker size, reveal default, quest area/giver/turn-in toggles, grey range, arrow on/style/arrival distance, Blizzard waypoint mirror, /way claim, minimap on/size/zoom/shape. Registers via Settings.RegisterCanvasLayoutCategory if present, else InterfaceOptions_AddCategory, else opens its own window. Reachable from the new gear toolbar icon and /mm config. Settings apply live (UI:ApplySettings); arrow has a classic and a bold style. Other modules extend the page with Options.Add.

- Punchlist 5: Window scale (0.7-1.5, centre stays put), window opacity and a lock toggle (window, minimap and arrow positions; hides the resize grip) on the options page, plus Reset window. Quest list visibility was already saved (db.tracker).

- Punchlist 6: Launcher button on Blizzard's minimap (left-click toggles the map, right-click opens options, drag moves it around the edge; can be turned off in options). Meridian's own minimap now shows a fixed N marker and your coordinates.

- Punchlist 7: Super-track integration. Shift-click in the quest list also calls C_SuperTrack.SetSuperTrackedQuestID so Blizzard's arrow matches (option; clears with the arrow target). Ctrl-click focuses a quest: other quest areas and quest markers fade (Questie-style); the focused row is marked with >.

- Punchlist 8: Quest list upgrades. Sort button cycles zone / level / distance (on the current map) / log order; zone mode groups by the log's zone headers with collapsible headers (remembered); rows show level and either done or objective progress as text (not colour alone); mouse-wheel scrolls; tooltips add level, zone and which party members are on the quest (C_QuestLog.IsUnitOnQuest; the API gives membership, not their objective counts).

- Punchlist 9: Coordinate readouts. Main map: cursor coordinates (bottom-left) plus a new "You: x, y" readout (bottom-centre); minimap already shows yours. Click any readout to open a pre-selected box with "/way Zone x y" for Ctrl-C (WoW has no clipboard API); Shift-click puts it in the chat input instead.

- Punchlist 10: Tooltip detail modifiers (Tooltips.lua). Hover shows a short tooltip; holding Shift (redraws live when pressed) adds XP/money/item rewards for logged quests (GetQuestLogReward*) and prerequisites, mutually exclusive quests and the next quest in the chain (QuestieDB, guarded). Giver tooltips now name the NPC/object and its level range.

- Punchlist 11: Accessibility pass. Every marker type already has its own silhouette (teardrop, !, ?, arrowhead, star, diamond, square) with a black outline; new: colour-blind-safe palette (Okabe-Ito) for quest areas and markers, text size option (own Font objects), high-contrast mode (outlined text, opaque panels, white borders, brighter icons), and toggle buttons now show a check mark and underline as well as colour.

- Punchlist 12: Controller support, minimal and OFF by default (Controller.lua; options checkbox or /mm pad). Uses Frame:EnableGamePadButton/Stick with OnGamePadButtonDown/OnGamePadStick: stick pans (dead zone, squared response), triggers zoom, shoulders cycle the quest list order and centre on each, PAD1 centres on you, PAD2 closes, PAD4 toggles the list; a hint line appears while enabled. Nothing is registered until enabled. Stick/button identifiers and focus acquisition are unverified; toolbar buttons are not controller-navigable (mouse-only), the toolbar has key bindings as a substitute.

- Punchlist 13: Search and journey (Search.lua). Search box in the toolbar finds zones, logged quests, any QuestieDB quest (via the starter index, built on first use) and quest-giver NPCs on the maps on screen; click or Enter jumps there and drops a clearable marker; rows spell out the kind. New list icon next to the box (or /mm here) lists quests you can accept in the current zone, sorted by level. /mm find <text> fills the box.

- Punchlist 14: Other pin sources, minimal and OFF by default (Pins.lua): flight paths (harvested via C_TaxiMap.GetAllTaxiNodes when a flight master map opens, remembered in saved data, shown on the continent view), rares/treasures from C_VignetteInfo for your current zone, and area POIs from C_AreaPoiInfo; separate toggles on the options page. Events are registered only while a type is on. Canvas gained PosToCanvas so pins can be placed from continent coordinates. No per-pin scale/alpha or profiles (not HandyNotes-complete).

- Punchlist 15: Localization scaffolding and in-client checklist. Locale.lua (M.L, English text as key, never blank), Locales/enUS.lua (generated key list via tools/extract_strings.py), Locales/deDE.lua (small unreviewed starter); toolbar, options page, bindings, sort names and launcher text go through L. docs/test-checklist.md covers every untested feature; README status lists them. Chat messages are not yet localized.
